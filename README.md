# ReflectionTalks

Site-ul ReflectionTalks (Sabina Oulham), refăcut în React 19 + TypeScript + Vite.
Codul aplicației e în [`reflection_talks/`](reflection_talks/) — vezi README-ul de acolo
pentru structură și rulare locală.

## Deploy

La fiecare push pe `main`, workflow-ul `.github/workflows/deploy.yml` face build și
publică site-ul pe GitHub Pages: https://ochianiulian.github.io/ReflectionTalks/

O singură dată, în repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
